# 📘 SDLC AI Verifier  
**Design and Development of an SDLC-based Framework for Verifying AI-based Decision Support Systems**

---

## 📌 Overview

**SDLC AI Verifier** is an AI-powered web application that analyzes software project artifacts and evaluates their compliance with different phases of the **Software Development Life Cycle (SDLC)**.

The system acts as a **Decision Support System (DSS)** by providing automated analysis, scoring, and recommendations to help improve software quality and development practices.

---

## 🎯 Objectives

- Verify adherence to SDLC phases using AI-based analysis  
- Provide automated feedback for each SDLC phase  
- Identify gaps in documentation, design, testing, and maintenance  
- Support developers and researchers in decision-making  
- Improve overall software quality and process maturity  

---

## SDLC Phases Covered

The framework evaluates the following SDLC phases:

1. Requirements Analysis  
2. System Design  
3. Implementation  
4. Testing  
5. Deployment  
6. Maintenance  

Each phase is scored individually and contributes to an **overall SDLC compliance score**.

---

## 🚀 Features

- 📂 Upload multiple project files  
- 🤖 AI-based SDLC phase analysis  
- 📊 Phase-wise compliance scores  
- 🧠 AI-powered chat assistant for guidance  
- 📋 Strengths and recommendations for each phase  
- 🔍 Expandable analysis cards  
- 🎨 Clean, responsive, and user-friendly interface
